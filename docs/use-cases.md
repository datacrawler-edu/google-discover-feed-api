# Common use cases

- **Publisher visibility.** Group cards by `domain` and compare `positionInSample` across snapshots of the same market.
- **Market comparison.** Run the [market batch](../examples/python/batch_markets.py) and retain one file per run. Country selection can still return publishers from other markets.
- **Spreadsheet export.** Run `python examples/python/export_csv.py RUN_ID discover.csv` to export an existing Dataset.
