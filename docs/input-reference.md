# Input reference

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `country` | string | `us` | Market code from the Actor's Input tab. Example values include `us`, `es` and `gb`. |
| `maxArticles` | integer | 60 | Maximum number of unique cards to save. Accepts 1–1000. |

The [sample input](../data/sample-input.json) sends both fields. The run's `maxTotalChargeUsd` query option sets a separate spending limit.
