# Run without code

1. Open [Google Discover Feed Scraper](https://apify.com/datascraperes/google-discover-scraper?fpr=edudata) and sign in to Apify.
2. Choose a **Country** and a **Maximum articles** cap. Five cards is a convenient first test.
3. Select **Start** and wait for the run to finish.
4. Open **Dataset** to inspect rows. Use **Export** to download JSON or CSV.
5. Compare the saved rows with the collection status and stop reason before treating a snapshot as complete.
